# RSS Widget

Windows 11 のデスクトップに常駐させておける、半透明のフローティングパネル型 RSS/Atom
リーダーです。ブラウザを開かなくても、デスクトップの隅に置いたまま複数サイトの更新を
まとめて確認できます。

## インストール方法

配布形式は2種類あります。どちらも中身は同じアプリです。

- **インストーラ版**（`.msi` / `.exe`）: 実行するとWindowsに通常のアプリとしてインストール
  されます。データは通常のアプリと同じ場所（ユーザーごとのアプリデータフォルダ）に保存されます。
- **ポータブル版**（`dist-portable` フォルダ、または配布された zip）: インストール不要で、
  フォルダの中の `rss-widget.exe` をそのまま起動するだけで使えます。データはこのフォルダの
  中の `data` フォルダに保存されるため、フォルダごとコピーすればUSBメモリなどに入れて別の
  PCでもそのまま使えます。

どちらも初回起動時に少し時間がかかることがありますが、2回目以降は数秒で起動します。

## 基本操作

### フィードを追加する

画面下部の RSS アイコン（フィード管理）を開き、上部の入力欄に追加したいサイトの URL を
入力して「追加」を押します。

- RSS/Atom フィードのURL（例: `https://example.com/feed.xml`）をそのまま入力しても、
- サイトのトップページのURL（例: `https://example.com/`）を入力しても、自動でフィードを
  探して追加します。

ただし、すべてのサイトがRSS/Atomフィードを提供しているわけではありません。記事系のサイト
以外や、一部のサイトからはフィードを取得できない場合があります。

他のRSSリーダーからまとめて移行したい場合は、同じ画面の「インポート」ボタンから
OPMLファイル（多くのRSSリーダーがエクスポートできる標準形式）を読み込めます。逆に
「エクスポート」で今のフィード一覧をOPMLファイルに書き出せます。

### フィードを管理する

同じフィード管理画面から、各フィードについて以下ができます。

- 削除（ゴミ箱アイコン）
- 名前の変更
- 更新間隔の変更（未設定なら30分ごとに自動更新）
- ジャンル（フォルダ）分け・タグ付け
- 並び替え

### 記事を読む

- 記事をクリックすると既定のブラウザ（または設定でアプリ内リーダーを選んでいればアプリ内）
  で開き、自動的に既読になります
- 行の右端の「✓」マークをクリックすると、開かずに既読/未読を手動で切り替えられます
- 星マークでブックマーク（お気に入り）できます
- 画面上部の入力欄で記事のタイトル・本文を検索できます
- 「すべて既読」「すべて未読」でまとめて切り替えられます
- 表示モードは「カード」（サムネイル付き）「リスト」「コンパクト」（タイトルのみ）の
  3種類から選べます
- フィード選択のプルダウンから、特定のフィードだけ・特定のジャンルだけに絞り込めます

### ブックマークとゴミ箱

星マークで付けたブックマークは、絞り込み表示（星アイコン）で一覧できます。この絞り込み
表示中は各記事にゴミ箱アイコンが表示され、クリックするとブックマークをタイムラインから
削除できます。誤って削除した場合は、画面上部のゴミ箱アイコンから「ゴミ箱」画面を開き、
「元に戻す」でいつでも復元できます（削除後30日間はゴミ箱に残ります。それ以降は自動的に
完全に削除されます）。

### 閲覧履歴

一度読んだ記事はゴミ箱アイコンの隣にある時計アイコンの「既読履歴」画面から確認できます。
フィードや記事自体が後から削除されても、「いつ読んだか」の記録はここに残ります。履歴の
保持期間は設定画面から変更できます（既定は無期限です）。

## 設定でできること

パレットアイコンから設定画面を開けます。

- **スキン / 不透明度**: パネル全体の配色と透明度
- **カードサイズ / カードの間隔**: カード表示モードの見た目の調整
- **フォント**: パソコンにインストール済みのフォントから選択
- **記事を開く方法**: 既定のブラウザで開くか、アプリ内で読むか
- **常に最前面に表示**: 他のウィンドウの後ろに隠れないようにする
- **位置を固定**: ドラッグでうっかり動かさないようにする
- **タイトルバーを表示**: オフにすると上部のバーが消え、より省スペースになります
- **閉じるボタンでタスクトレイに格納**: オンだと×ボタンで閉じてもタスクトレイに常駐した
  ままになります（後述）。オフだと通常のアプリと同じように×ボタンで終了します
- **外部画像を読み込まない**: 記事のサムネイルなどの画像を自動で読み込まないようにします。
  一部のフィードは画像に「読者が開いたかどうか」を検知する仕組み（トラッキングピクセル）を
  仕込んでいることがあり、それを避けたい場合にオンにしてください
- **閲覧履歴の保持期間**: 既読履歴を自動で削除するまでの日数（7日/30日/90日/無期限）
- **データ保存先**: フィードや記事を保存するフォルダを変更できます（変更にはアプリの
  再起動が必要です）

## タスクトレイの使い方

「閉じるボタンでタスクトレイに格納」がオンの場合、×ボタンで閉じてもアプリはタスクトレイ
（画面右下の通知領域）に常駐し続けます。タスクトレイのアイコンを右クリックすると次の
メニューが出ます。

- **表示/非表示**: ウィンドウの表示・非表示を切り替え（アイコンを左クリックでも同じ）
- **更新**: すべてのフィードを手動で更新
- **終了**: アプリを完全に終了

## 既知の制限

- 日本語UIのみで、英語などへの切り替えはできません
- キーボードショートカットには対応していません（すべてマウス/クリック操作です）
- すべてのサイトがRSS/Atomフィードを提供しているわけではないため、フィードを追加できない
  サイトもあります
- フィードのジャンル（フォルダ）分けは1階層のみです
- デスクトップに常時貼り付けておく専用モードはありませんが、「位置を固定」+
  「常に最前面に表示」を組み合わせることで近い使い方ができます

## 開発

```sh
npm install
npm run tauri dev      # 開発起動（Vite + cargo run を同時に実行）
npm run build           # tsc の型検査 + vite build（フロントのみ）
npm run tauri build      # インストーラ (MSI/NSIS) 生成
npm run package:portable  # ポータブル版パッケージ生成（dist-portable/）
```

実装の詳細・アーキテクチャは [`CLAUDE.md`](./CLAUDE.md)、当初の仕様は
[`SPEC.md`](./SPEC.md) を参照してください。
