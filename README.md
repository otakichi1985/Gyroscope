# RSS Widget

Windows 11のデスクトップに置いて使える、半透明のRSS/Atomリーダーです。
いくつものWebサイトの新着記事を、ブラウザを巡回せず一つの小さなウィンドウで確認できます。

## いちばん簡単な始め方（ポータブル版）

1. 受け取ったZIPファイルを右クリックし、**「すべて展開」**します。
2. 展開したフォルダ内の `rss-widget.exe` をダブルクリックします。
3. 画面上部のRSSアイコンから「フィード管理」を開きます。
4. 同梱の `sample.opml` を「インポート」で選ぶと、サンプルの購読先をまとめて登録できます。
5. 「記事を更新」を押すと記事が表示されます。

`sample.opml` はお試し用です。不要なフィードはフィード管理画面のゴミ箱ボタンから削除できます。

> Windowsが「PCが保護されました」と表示した場合は、配布元が信頼できることを確認してから
> 「詳細情報」→「実行」を選びます。このアプリは現時点ではコード署名されていません。

## 配布形式とデータの保存場所

- **ポータブル版**: インストール不要です。設定・フィード・記事は、アプリと同じ場所の
  `data` フォルダに保存されます。バックアップするときは、アプリを終了してからフォルダごとコピーします。
- **インストーラ版**（`.msi` / `.exe`）: Windowsへ通常のアプリとしてインストールします。
  データはユーザーごとのアプリデータフォルダに保存されます。

ポータブル版は、ZIPの中から直接起動せず、必ず先に展開してください。アプリの使用中に
`rss-widget.exe`、`.portable`、`data` フォルダを別々の場所へ移動しないでください。

## 基本操作

### フィードを追加・管理する

画面上部のRSSアイコンからフィード管理を開きます。

- サイトのURL、またはRSS/AtomフィードのURLを入力して「追加」
- `sample.opml` や他のRSSリーダーから書き出したOPMLを「インポート」
- 現在の購読一覧を「エクスポート」でバックアップ
- 名前変更、更新間隔、通知、ジャンル分け、並べ替え、削除

サイトによってはRSSを公開しておらず、登録できない場合があります。更新間隔を指定しない場合は
30分ごとに確認します。

### 記事を読む

- 記事をクリックすると、既定ではアプリ内リーダーで開いて既読になります。
- 行末のチェックマークで、開かずに既読・未読を切り替えられます。
- 星マークでブックマークできます。
- 検索欄から記事のタイトルと本文を検索できます。
- 「カード」「リスト」「コンパクト」の3種類から表示方法を選べます。
- フィードやジャンルを選んで、表示する記事を絞り込めます。

ブックマーク表示中に記事を削除しても、30日間はゴミ箱から復元できます。読んだ記事は
時計アイコンの「既読履歴」で確認でき、保持期間は設定から変更できます。

## 設定

パレットアイコンから次の項目を変更できます。

- システム／ライト／ダーク表示、13種類のカラーテーマ、不透明度、カードの大きさと間隔、英数字／日本語フォント
- 記事をアプリ内で読むか、Webブラウザで開くか
- 常に最前面、位置固定、タイトルバー、アイコンの説明表示
- 閉じるボタンでタスクトレイへ格納するか
- 外部画像を読み込まないプライバシー設定
- 既読履歴の保持期間、データ保存先

設定は「見た目」「動作」などの見出しを押すと開閉できます。ターミナルテーマだけは、
端末風の見た目と読みやすさを保つため、選択している間はダーク表示になります。

初期状態は開発時に確認した外観（不透明度85%、モノクロ、中サイズのカード、標準間隔）と、
アプリ内リーダー、説明表示、タスクトレイ格納が有効になっています。

## タスクトレイと終了方法

初期設定では、右上の×を押しても終了せず、画面右下のタスクトレイに隠れます。
見当たらない場合は、タスクバー右側の `^` を押してRSS Widgetのアイコンを探してください。

- 左クリック: ウィンドウを表示・非表示
- 右クリック→「更新」: すべてのフィードを更新
- 右クリック→「終了」: アプリを完全に終了

## 困ったとき

- **記事が出ない**: 絞り込みや検索を解除し、「記事を更新」を押します。フィード管理に赤い警告が
  出ていれば、サイト側の停止やURL変更の可能性があります。
- **ウィンドウが消えた**: タスクトレイのRSS Widgetアイコンを左クリックします。
- **設定や記事を移したい**: OPMLは購読先だけを移します。ポータブル版の全データを移す場合は、
  アプリを終了してフォルダ全体をコピーします。
- **起動できない**: ZIPを展開済みか確認し、フォルダを書き込み可能な場所（デスクトップなど）へ移します。

## 対応環境と制限

- Windows 11向け、日本語UIのみです。
- キーボードショートカットには未対応です。
- ジャンル分けは1階層です。
- Webサイトの仕様によって、記事本文・画像・更新日時を完全に取得できない場合があります。
