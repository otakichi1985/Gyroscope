# CONNECTION_POSSIBILITY_CHECKLIST.md

将来の機能を先回りして実装するための文書ではない。
現在の変更で、将来の接続可能性を不必要に潰さないための確認用。

# Check

- [ ] UIと中核ロジックを不必要に密結合していないか
- [ ] 外部から利用する入口を完全に潰していないか
- [ ] データ形式を特定UIや特定ベンダーへ不必要に固定していないか
- [ ] 将来単体で切り出せそうな処理を一体化しすぎていないか
- [ ] AI / CLI / 別アプリなど別の操作主体から利用できる余地を残せるか
- [ ] 他プロダクトと接続したくなった場合、現在の構造が大きな障害にならないか
- [ ] 今ほぼ追加コストなしで残せる境界・入口・単純な入出力があるか
- [ ] 将来のためだけの機能や抽象化を先行実装しようとしていないか


# Relevant Possibilities

これは実装要件ではない。
