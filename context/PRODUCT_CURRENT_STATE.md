# PRODUCT_CURRENT_STATE.md

このプロダクトの現在地だけを記録する。
過去の状態や開発史は残さない。

# Current Purpose

Gyroscopeは、複数の情報源の新着をブラウザで巡回せず、Windowsデスクトップ上の小さな常駐ウィンドウで継続的に確認するためのアプリ。


# Current Capabilities

- RSS / AtomフィードをURLまたはサイトURLから追加し、定期更新できる。
- BOOTHショップを専用の情報源として登録し、新着商品を監視できる。
- 記事をタイムラインで表示し、検索、フィード・ジャンル絞り込み、昇順・降順切替ができる。
- カード、リスト、コンパクトの3表示を切り替えられる。
- 記事をアプリ内リーダーまたは既定ブラウザで開き、既読・未読、スター、既読履歴を管理できる。
- スター付き記事をゴミ箱へ移し、一定期間内なら復元できる。
- フィードの名前、ジャンル、順序、更新間隔、通知を管理できる。
- OPMLによる購読一覧のインポート・エクスポートができる。
- タスクトレイ常駐、自動更新、通知、常に最前面、位置固定を利用できる。
- ライト・ダーク・システム表示、複数スキン、フォント、不透明度、カード寸法などを変更できる。
- インストーラ版とポータブル版があり、データ保存先を変更できる。
- GitHub Releasesを使った更新確認、実行ファイル更新、1世代のロールバックがある。


# Current Limitations

- Windows 11向けで、日本語UIのみ。
- キーボードショートカットには未対応。
- ジャンル分けは1階層。
- 情報源側の仕様により、本文・画像・公開日時を完全に取得できない場合がある。
- フロントエンドの自動テストとアプリ全体のE2Eテストは現在見当たらず、GUIの視覚・操作確認にはHuman確認が残る。
